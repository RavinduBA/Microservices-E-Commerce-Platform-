

# Spring Boot Microservices E-Commerce Application

This is a ongoing project on developing a **Microservices-based e-commerce application**. It demonstrates how to build and deploy applications using **Microservices Architecture**, **Spring Boot**, **Spring Cloud**, **Docker**, and **Kubernetes**.

---

## 📌 Project Overview

This application simulates a simple e-commerce platform where customers can order products. The project is designed to demonstrate **Microservices architectural patterns** rather than a full-featured e-commerce platform.

The application consists of the following services:

- **Product Service** – Manages product information.
- **Order Service** – Handles customer orders.
- **Inventory Service** – Tracks product stock.
- **Notification Service** – Sends notifications to customers.

---

## 🎯 Tutorial Series

The project is part of a Spring Boot Microservices tutorial series, covering key concepts and patterns:

| Part | Topic |
|------|-------|
| 1    | Building REST-based applications using Spring Boot 3 |
| 2    | Synchronous Inter-Service Communication using Spring Cloud OpenFeign |
| 3    | Service Discovery Pattern using Spring Cloud Netflix Eureka |
| 4    | API Gateway Pattern using Spring Cloud Gateway |
| 5    | Microservices Security using Keycloak |
| 6    | Circuit Breaker Pattern using Spring Cloud CircuitBreaker with Resilience4J |
| 7    | Event Driven Architecture Pattern using Kafka |
| 8    | Observability Pattern: Distributed Tracing (OpenTelemetry & Grafana Tempo), Log Aggregation (Grafana Loki), Metrics Collection (Prometheus & Grafana) |
| 9    | Containerization using Docker and running applications via Docker Compose |
| 10   | Migrating Docker Compose workloads to Kubernetes |

---

## ⚙️ Technologies Used

- **Backend:** Spring Boot, Spring Cloud (Eureka, OpenFeign, Gateway, CircuitBreaker)
- **Security:** Keycloak
- **Messaging/Event-Driven:** Apache Kafka
- **Containerization & Orchestration:** Docker, Kubernetes
- **Observability:** Prometheus, Grafana, OpenTelemetry, Grafana Loki
- **Database:** MySQL
- **Build Tool:** Maven
