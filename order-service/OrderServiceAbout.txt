When an order is placed via the API, it is converted to an Order entity and saved to the t_orders table in MySQL using Spring Data JPA. The application connects to MySQL using the configuration in application.properties.

Flyway migrations?
Flyway migrations are used in this project to automatically manage and version the database schema.
When the application starts, Flyway checks for migration scripts (like V1__init.sql) and applies them to the database if they haven't been run yet. This ensures the required tables (such as t_orders) are created and the schema stays consistent across different environments and deployments.
